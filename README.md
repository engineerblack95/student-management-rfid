## 📖 Project Overview

A professional Student Management and RFID Attendance System combining:
- **Embedded hardware** (ESP32 + MFRC522 RFID reader + LEDs + buzzer)
- **Wi-Fi networking**
- **Backend REST API** (Node.js + Express)
- **Relational database** (PostgreSQL)
- **Modern dashboard** (React.js)

Full data flow: **RFID Card → MFRC522 → ESP32 → LEDs/Buzzer → Wi-Fi → Node.js API → PostgreSQL → React Dashboard → Admin**
